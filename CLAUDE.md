## Capture (Claude, end of every session)

1. Update the current phase's task table in [ROADMAP.md](ROADMAP.md): state and what's next.
2. Append any decision to [DECISIONS.md](DECISIONS.md) (`### YYYY-MM-DD — …`, why, who).
3. Update [notes/live-state.md](notes/live-state.md) if anything deployed.
4. Append anything that cost time to [LEARNINGS.md](LEARNINGS.md), with the rule it taught.
5. Grow `notes/<topic>.md` when a how-to becomes reusable; update the existing file, don't duplicate it.
